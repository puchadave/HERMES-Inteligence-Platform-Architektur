# Security Policy

Do not commit credentials, case data, raw evidence, personal communications, API keys, VPN profiles, or model files.

Report security defects through a private GitHub security advisory for this repository. Include affected commit, deployment profile, reproduction steps, and observed impact.

The production baseline requires:

- unique secrets generated by `scripts/bootstrap.sh`;
- TLS at the external reverse proxy;
- Keycloak MFA for privileged roles;
- no direct publication of NATS, Qdrant, Valkey, database, or evidence ports;
- immutable release tags and generated SBOMs;
- reviewed updates to SearXNG overlays.
